# 🇳🇬 Naija Web Run — 3D Lagos Endless Runner

A fast-paced, mobile-first 3D endless runner browser game built with **Three.js**, **React Three Fiber**, and **Vite**. Run through the bustling streets and mystical outskirts of Lagos, dodge dynamic obstacles, outpace the relentless forest guardian, bank authentic Naira, and build your luxury fleet and real estate empire!

---

## 🚀 Key Features

- **🎮 High-Performance 3D Gameplay**:
  - Built on React Three Fiber and Three.js with custom GLSL curvature shaders and procedural world generation.
  - Smooth lane-switching, jumping, sliding, and obstacle collision dynamics.
  - Multi-hazard mechanics with recovery sprints and guardian pursuit states.

- **💵 Calibrated Nigerian Economy**:
  - **₦1,000 Claims**: Every authentic Naira note collected in a run adds ₦1,000 directly to your active haul.
  - **Calibrated Distance Scoring**: Steady, balanced score progression (1 pt/meter run + 25 pts per currency note + lifestyle perk multipliers).
  - **Federal Starter Grant**: Every registered runner receives an initial ₦250,000 grant credited to their permanent vault.

- **🏎️ Real-World Luxury Assets & Shop**:
  - Authentic Nigerian market pricing and real photographic rendered assets:

- **🛡️ Runner Accounts & Cloud Vault**:
  - Register with **just username & password** (no spammy forms or email verification).

## 🛠️ Tech Stack

- **Framework**: React 18
- **3D Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Audio Engine**: Web Audio API Procedural Synthesizer
- **Bundler**: Vite 5
- **Styling**: Vanilla Modern CSS (Glassmorphism & Responsive Flex/Grid)

## 📦 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/GoodnessTech/naija-run.git
   cd naija-run
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for **instant 1-click zero-config deployment**:

1. Import `GoodnessTech/naija-run` into your [Vercel Dashboard](https://vercel.com).
2. Framework Preset: **Vite** (automatically detected).
3. Root Directory: `./` (leave default).
4. Click **Deploy**!
